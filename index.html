3.1 Ramas

Una rama me permite experimentar sin romper main.

git switch -c feature/nueva-idea

3.2 Fusiones y conflictos

Un conflicto aparece cuando dos ramas cambian la misma línea.

Linea para conflicto main.

git merge feature/seccion-3-2

3.4 Historial y recuperación

Con log, diff, revert, reset, reflog y stash nada se pierde.

git reflog

Práctica de comandos

Herramientas para manipular el historial y pausar trabajo en progreso.

  • git stash: Guarda cambios pendientes sin hacer commit para limpiar la rama de trabajo.
  • git rebase: Reaplica los commits de la rama actual sobre otra base, logrando un historial lineal.
  • git cherry-pick: Trae e inserta un commit específico desde otra rama.
git stash pop git rebase main
