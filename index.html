2.2 Mi primer repositorio

Con git init creé la carpeta oculta .git.

Estados: untracked, modified, staged y unmodified.

2.3 Ciclo de vida

  1. Editar el archivo
  2. Revisar con git status

*.log

3.1 Ramas

Una rama me permite experimentar sin romper main.

git switch -c feature/nueva-idea

3.2 Fusiones y conflictos

Un conflicto aparece cuando dos ramas cambian la misma línea.

Linea para conflicto main.

git merge feature/seccion-3-2
